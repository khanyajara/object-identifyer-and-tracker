## 🔬 About The Project

A **real-time object detection and tracking system** powered by **Ultralytics YOLOv8** and **Deep SORT** algorithm. Built with a clean, interactive **Streamlit** interface supporting webcam feeds, video files, and static images — with class filtering, FPS monitoring, and CSV/video export.

> 🎯 Designed to demonstrate the integration of state-of-the-art CV models with a production-ready interactive web UI.

<br/>

<div align="center">

| 🎯 Detection | 🔍 Tracking | 📥 Input Modes | 📤 Output |
|:---:|:---:|:---:|:---:|
| YOLOv8 (n/s/m/l/x) | Deep SORT (toggleable) | Webcam · Video · Image | Processed video + CSV |

</div>

## ✨ Features

<br/>

| 🤖 AI & Detection | 🎛️ Controls | 📤 Output & Export |
|:---|:---|:---|

## 🚀 Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/aryansengar007/Object-Detection-and-Tracking.git
cd Object-Detection-and-Tracking
```

**2. Create & activate virtual environment**

```bash
# Windows
venv\Scripts\activate
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
# or manually:
pip install ultralytics opencv-python deep_sort_realtime streamlit
```

**4. Download YOLOv8 model weights** *(e.g. `yolov8n.pt`)*

From the official repo: [github.com/ultralytics/ultralytics](https://github.com/ultralytics/ultralytics)

**5. Run the app**

```bash
streamlit run main.py
```

> ✅ Opens at `http://localhost:8501`
